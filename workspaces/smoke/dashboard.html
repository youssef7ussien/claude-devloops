  • ✓ M01-T04 Unit tests HEALTH-1
    Add node:test tests covering the status rendering logic: an ok response gives 'Status: ok'; a failed fetch or a non-2xx response gives 'Status: unavailable'. Put the logic in a small pure function that can be imported and tested without a browser.
