# US01: Count the color changes

This story extends the existing Color Clicker application (a page whose background changes to
a random color on each click, with `GET /api/state` and `POST /api/changes`). Keep everything
it already does.

As a visitor, I see how many times the color has changed, and I can start over.

## Backend
- `GET /api/state` and `POST /api/changes` also return `"changes": <integer>`, the number of
  color changes since the server started or was reset. A new server starts at 0.
- Each `POST /api/changes` adds 1 to `changes`.
- `POST /api/reset` sets the color back to `#FFFFFF` and `changes` to 0, and returns the state
  with status 200.

## Frontend
- The page shows "Changes: N", with N taken from the server.
- Each click increases the number shown by 1.
- A "Reset" button sends `POST /api/reset`: the background goes back to `#FFFFFF` and the
  count to 0. Clicking the button does not count as a change.
